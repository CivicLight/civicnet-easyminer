# CivicNet EasyMiner

One-click GUI miner for **CivicNet (CIVIC)** — CPU mining made simple, no command line needed.

Built on [cpuminer-opt](https://github.com/JayDDee/cpuminer-opt) with the `civiclight` algorithm — CPU-mineable and ASIC-resistant.

## Features

- Simple GUI — just paste your wallet address and click Start
- Adjustable CPU thread count
- Built-in pool selector — mine on the Official Pool, NitroPool, or RabbitMiner without any manual config
- Live mining log

## Pool options

| Pool | Location |
|---|---|

| NitroPool | EU / AU / US |
| RabbitMiner | NL / FI |

## Download

Grab the latest release from the [Releases page](https://github.com/CivicLight/civicnet-easyminer/releases).

## Usage

1. Download and run `CivicNet EasyMiner.exe`.
2. Paste your CIVIC wallet address (starts with `civc1...`).
3. Select a pool from the dropdown.
4. Choose how many CPU threads to use.
5. Click **Start Mining**.

That's it — no manual stratum config, no command line.
